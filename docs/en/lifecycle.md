# Publishing lifecycle

> This document is a translation. The Japanese specification is canonical in case of discrepancies.

`draft → generated → validated → published → deprecated → archived`

- `draft`: being edited, not public.
- `generated`: structured output exists.
- `validated`: schema and required quality gates passed.
- `published`: available to readers.
- `deprecated`: retained but no longer preferred.
- `archived`: retained as history.

Content may return to `generated` or `draft` for correction. `supersedes` is separate from lifecycle state. Older versions can coexist as deprecated or archived rather than being deleted.
