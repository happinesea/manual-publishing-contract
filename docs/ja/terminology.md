# Terminology

| 日本語 | English | 简体中文 | 意味 |
| --- | --- | --- | --- |
| 原典 | Source Document | 源文档 | 変換元artifact |
| マニュアル系列 | Manual Family | 手册系列 | 複数版を束ねるidentity |
| マニュアル版 | Manual Version | 手册版本 | 特定言語・版のmanual |
| 節 | Section | 章节 | Web公開の論理単位 |
| 根拠 | Evidence | 证据 | claimから原典へ戻る参照 |
| 来歴情報 | Provenance | 来源追踪信息 | 生成元と変換関係 |
| 公開状態 | Publication Status | 发布状态 | lifecycle上の状態 |
| 意味的忠実性 | Semantic Fidelity | 语义忠实度 | 意味・構造・数値等の保持 |
| 視覚的忠実性 | Visual Fidelity | 视觉忠实度 | 見た目やpaginationの再現度 |

`manual_id`は個別manual、`family_id`は系列、`source_id`は原典artifactを識別します。
