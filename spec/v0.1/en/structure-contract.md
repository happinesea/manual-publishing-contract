# Structure Contract v0.1

> This document is a translation. The Japanese specification is canonical in case of discrepancies.

Each section MUST have a stable `section_id`, title, `source_id`, one or more source pages, and a Web path. Implementations SHOULD document the page-numbering convention used to identify pages in the artifact.

A Web section may span several source pages. One-PDF-page-per-Web-page MUST NOT be required. Tables and figures MAY carry an ID and source page.

See the [section schema](../../../schema/v0.1/section.schema.json).
